# แอปติวสอบ

แอปทดสอบตัวเองสำหรับสอบกลางภาค รองรับหลายวิชาในแอปเดียว

| วิชา | ขอบเขต |
|---|---|
| **Multimedia Technology** | 06016403 · บทที่ 1–6 |
| **Database Systems** | Coronel & Rob, Database Principles 10th ed. · บทที่ 1, 3, 4 |

Next.js (App Router) + TypeScript + Tailwind — เป็น static ทั้งหมด ไม่มี backend / database
ทุกอย่างเก็บใน localStorage ของเบราว์เซอร์

## รันในเครื่อง

```bash
npm install
```

```bash
npm run dev
```

## Deploy ขึ้น Vercel

1. push โปรเจกต์นี้ขึ้น GitHub
2. ที่ vercel.com กด **Add New → Project** แล้วเลือก repo นี้
3. Vercel ตรวจเจอ Next.js เอง กด Deploy ได้เลย ไม่ต้องตั้งค่าอะไรเพิ่ม


## พฤติกรรมที่ตั้งใจไว้

- **ทำค้างได้** ทุกครั้งที่ตอบหรือเปลี่ยนข้อ จะบันทึกลงเครื่องทันที ปิดแล้วเปิดใหม่มีปุ่ม "ทำต่อ" บนหน้าแรก
- **เฉลยทันทีเสมอ** ตอบแล้วเห็นคำอธิบายเลย ไม่ว่าจะจับเวลาหรือไม่ การจับเวลาเป็นแค่นาฬิกานับถอยหลัง หมดเวลาแล้วส่งอัตโนมัติ
- **เวลาเดินเฉพาะตอนเปิดหน้าทำข้อสอบ** ปิดหน้าไปนาฬิกาหยุด กลับมาแล้วนับต่อ บันทึกเวลาลงเครื่องทุก 15 วินาที
- **แบ่งข้อเท่ากันทุกบท** บทไหนข้อไม่พอโควตา ส่วนที่ขาดจะเกลี่ยไปบทอื่นให้ครบตามจำนวนที่ขอ
- **แยกวิชาเด็ดขาด** ชุดข้อสอบหนึ่งชุดมีได้วิชาเดียว วิชาที่เลือกไว้ล่าสุดถูกจำไว้ในเครื่อง
  และหน้าเลือกบทกับหน้าตั้งค่าจะแสดงเฉพาะบทของวิชานั้น

## การเพิ่มข้อสอบ

เพิ่มออบเจ็กต์ลงในอาร์เรย์ของไฟล์บทที่ต้องการ

ข้อปรนัย:

```ts
{
  id: "ch3-gen-1",
  chapter: "ch3",
  source: "generated",      // "past" = ข้อสอบจากควิซ
  type: "mcq",
  stars: 2,                 // 1–3
  tags: ["jpeg"],           // ต้องมีอยู่ใน data/tags.ts
  prompt: "…",
  figure: "convolution",    // ไม่บังคับ — key ใน components/Figures.tsx
  choices: [
    { id: "a", text: "…", why: "เหตุผลว่าทำไมถูก/ผิด" },
    { id: "e", text: "ถูกทุกข้อ", why: "…", pin: true },  // pin = ไม่ถูกสลับตำแหน่ง
  ],
  answer: "a",
  explanation: "…",
}
```

โจทย์คำนวณ:

```ts
{
  id: "ch3-calc-9",
  chapter: "ch3",
  source: "generated",
  type: "numeric",
  stars: 2,
  tags: ["image-filesize"],
  prompt: "…",
  answer: 18,
  tolerance: 0.1,     // ค่าคลาดเคลื่อนสัมบูรณ์ที่ยอมรับ
  unit: "MB",
  solution: "วิธีทำทีละขั้น",
  explanation: "…",
}
```

`pin: true` ใช้กับตัวเลือกอย่าง "ถูกทุกข้อ" / "ไม่มีข้อถูก" ซึ่งต้องอยู่ท้ายเสมอ
ไม่งั้นเมื่อสลับตัวเลือกแล้วโจทย์จะอ่านไม่รู้เรื่อง

ถ้าโจทย์ต้องมีตารางข้อมูลประกอบ ให้ใส่ฟิลด์ `table` แทนการวาดตารางในข้อความ
เพราะฟอนต์ของเนื้อหาไม่ใช่ monospace ตาราง ASCII จะเบี้ยว

```ts
table: {
  caption: "ตาราง C — CUSTOMER",   // ไม่บังคับ
  head: ["CUS_CODE", "CUS_LNAME"],
  rows: [
    ["1132445", "Walker"],
    ["1217782", "Adares"],
  ],
}
```

## การเพิ่มวิชาใหม่

1. เพิ่ม id ลงใน `SubjectId` และเพิ่ม id ของบทลงใน `ChapterId` ที่ `lib/types.ts`
   ตั้งชื่อบทให้ขึ้นต้นด้วยชื่อวิชา เช่น `db-ch1` เพื่อไม่ให้ชนกับวิชาเดิม
2. เพิ่มรายการลงใน `SUBJECTS`, `CHAPTERS` และ `TAGS` ที่ `data/tags.ts`
3. สร้างไฟล์ข้อสอบของแต่ละบท แล้ว import เข้า `ALL_QUESTIONS` ใน `data/index.ts`

หน้าจอทุกหน้าดึงรายชื่อบทจาก `CHAPTERS_BY_SUBJECT` อยู่แล้ว จึงไม่ต้องแก้ UI เพิ่ม

ทุกข้อเป็นระดับปานกลางถึงยาก (★★ 28 ข้อ · ★★★ 32 ข้อ) ไม่มีข้อระดับ ★
